# CartridgeControl 1.1.17

- В сверке базы добавлена кнопка «Скрыть без изменений» с количеством совпавших строк.
- Кнопка переключается в «Показать без изменений» и не сбрасывает уже принятые решения.
- Пагинация сверки учитывает только видимые строки.
- График динамики теперь использует те же бизнес-события, что и календарь.
- Синяя линия показывает сдачу на заправку, зелёная — выдачу, оранжевая — ремонт.
- Возле ненулевых точек каждой линии отображаются соответствующие значения.
