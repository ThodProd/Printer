# CartridgeControl 1.1.5

- Для строк «Нет в базе» добавлена кнопка «Добавить в базу».
- Новый принтер получает программный ID и связанный картридж так же, как при обычном ручном добавлении.
- Если модель картриджа не указана, программа подставляет её по существующему принтеру с такой же моделью устройства, когда соответствие однозначно. Картридж создаётся в любом случае.
- Для строк «Нет в файле» добавлены решения «Удалить из базы» и «Пометить списанным».
- Списанный принтер остаётся в базе со всеми связями и выделяется в списке принтеров отметкой «Списан».
- Все операции сверки записываются в журнал действий и применяются одним сохранением после создания резервной копии.
- Защита от устаревшей сверки не позволяет применить решение, если запись успела измениться после загрузки файла.

Для обновления закройте старую программу, распакуйте архив в новую папку и скопируйте туда папку `Data` рядом с `CartridgeControl.exe`. Перед копированием сохраните отдельную резервную копию `Data`.
