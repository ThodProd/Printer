# CartridgeControl 1.1.7

- Карточка принтера стала немного шире.
- Область с расходниками получила больше полезного пространства.
- Расходники располагаются до трёх блоков в ряд при достаточной ширине окна.
- Уменьшены шрифт, внутренние отступы, статус и вспомогательный текст внутри блоков расходников.
- Длинная модель расходника аккуратно обрезается, полное значение доступно во всплывающей подсказке.

Функциональность карточки, печати, списания и редактирования не менялась.

Действующая база из `windows-native-1.1.6/Data` при анализе и сборке не изменялась. Для перехода закройте старую программу, распакуйте новую версию и скопируйте папку `Data` только после создания отдельной резервной копии.
