# CartridgeControl 1.1.4

- Исправлено раскрытие блока «Формат и порядок столбцов» на странице сверки базы.
- Блок теперь остаётся внутри рабочей области и не обрезается границами карточки.
- Названия столбцов автоматически перестраиваются от одного столбца в узком окне до четырёх в широком.
- Длинные подписи переносятся внутри ячейки и не создают горизонтальную прокрутку страницы.

Весь функционал сверки из версии 1.1.3 сохранён без изменений. ID, связи и содержимое базы этим исправлением не затрагиваются.

Для обновления закройте старую программу, распакуйте архив в новую папку и скопируйте туда папку `Data` рядом с `CartridgeControl.exe`. Перед копированием сохраните отдельную резервную копию `Data`.
