# История изменений

## 2026-06-05 — Склад, ремонт, этикетки

### Этикетки
- При сканировании картриджа для **приёма на склад** галочка «Этикетка напечатана» выставляется автоматически (без уведомления, если уже стоит).
- При **авто-печати при регистрации** расходника `labelPrinted` тоже проставляется сразу.

### Новый расходник «со склада»
- В форме «Новый расходник» добавлена галочка **«со склада»** (вкл. по умолчанию, если на складе новых картриджей есть остатки).
- Список моделей из склада «новые картриджи» (только qty > 0), подходящие для принтера — первыми (★).
- При сохранении количество на складе уменьшается на 1; без галочки — свободный ввод модели.

### Ремонт и приём устройств
- Окно **«Решение / выполненные работы»** при приёме принтера с ремонта:
  - кнопка «Принять» на складе (одна позиция);
  - сканер на вкладке «Приём/Выдача» (режим приёма с ремонта);
  - **«Принять всё»** в партии — устройства по очереди, с индикатором «Устройство N из M».
- Картриджи в «Принять всё» принимаются сразу; устройства — только после ввода решения.

### Склад и синхронизация
- **Исправлен баг**: при повторном ремонте принтер пропадал со склада (остался только картридж). Причина — очистка ledger по старому выданному ремонту; теперь устройство не удаляется, если есть **активный** ремонт того же принтера.
- Исправлена выдача после ремонта: позиции со статусами `waiting` / `at_refill` тоже помечаются `issued`.
- Завершение ремонта во вкладке «Ремонт» обновляет `warehouseLedger.items` в статус `ready`.
- **Раскрытые партии** на вкладке «Склады» сохраняются в `localStorage` при переходе между вкладками.

### Сканер
- Ввод штрихкода всегда приводится к **английской раскладке** (даже при включённой русской клавиатуре).

## 2026-06-04 — Сборка и этикетки

### Этикетки на картриджах и драмах
- У каждого расходника флаг **«Этикетка напечатана»** (`labelPrinted`), хранится в базе данных.
- После успешной печати галочка выставляется автоматически.
- При повторной печати с установленной галочкой — предупреждение с подтверждением.
- Чекбокс доступен в карточке принтера, поиске, вкладке «Печать» и на главном экране (сканер).

### Документация и сборка на другом ПК
- **[BUILD.md](BUILD.md)** — полная инструкция: требования, команды, пути к артефактам.
- **[build/README.md](build/README.md)** — обязательные файлы: `icon.ico`, `sign-env.example`.
- Скрипты **`scripts/build-release.ps1`** (portable + NSIS + подпись) и **`scripts/sign-release.ps1`**.
- Команды npm: `release:build`, `release:sign`.
- Обновлён **[README.md](README.md)** — актуальные пути (`../Printer-release/`).
- В репозитории зафиксированы **`build/icon.ico`** и **`drivers/TSC_driver.cab`**.
