# CartridgeControl 1.1.2

- «Журнал заправок» заменён на «Журнал всех действий».
- Ручное добавление принтера создаёт отдельную запись о принтере и отдельную запись об автоматически созданном картридже.
- Централизованно журналируются добавление, изменение и удаление принтеров, расходников, сотрудников, ремонта и позиций нового склада; смена статусов, партии заправки, настройки, сверка базы и печать этикеток.
- Записи содержат категорию, объект, действие и подробности. По ним работает поиск и фильтры. Экспорт Excel включает новые поля.
- Старые записи `refillLog` остаются совместимыми и отображаются как операции с расходниками. Формат базы остаётся `version: 1`, ID и связи не меняются.
- Удалён переключатель технических записей: полный журнал показывается всегда.
- Интерфейс Windows по умолчанию открыт в масштабе 90%, как после одного шага Ctrl+колесо вниз. «Сбросить масштаб» возвращает к 90%.

Для обновления закройте старую программу, распакуйте архив в новую папку и скопируйте туда папку `Data` рядом с `CartridgeControl.exe`. Сначала сохраните отдельную копию `Data`.
