# CartridgeControl 1.1.3

- Полностью переработано оформление страницы сверки базы без изменения её логики.
- Добавлены компактная инструкция из трёх этапов, сводные показатели, легенда решений и аккуратная панель сохранения.
- Изменённые ячейки теперь явно показывают старое и новое значение; принятые, пропущенные и ожидающие решения состояния визуально различаются.
- Описание формата файла перенесено в раскрываемую подсказку, чтобы не занимать рабочую область.
- Подсказка формата адаптирована к узкому окну: столбцы переносятся по сетке и больше не выходят за границы страницы.
- Уменьшены кнопки-плашки расходников, «+ Добавить», табличные действия, фильтры, переключатели типа устройства и расходника.
- Базовый масштаб интерфейса остаётся 90%. Функции сверки, журналирования, база, ID и связи не изменены.

Для обновления закройте старую программу, распакуйте архив в новую папку и скопируйте туда папку `Data` рядом с `CartridgeControl.exe`. Перед копированием сохраните отдельную резервную копию `Data`.
